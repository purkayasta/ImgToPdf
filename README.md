# ImgToPdf

**Your images. One PDF. Entirely in your browser.**

Add images, arrange the pages, and download your PDF. Your files stay on your device.

### [Open ImgToPdf ↗](https://purkayasta.github.io/ImgToPdf/)

</div>

## Features

- **Drag, drop, arrange** — preview images and reorder pages before downloading.
- **Choose your size** — keep original quality, use high quality, or aim for 5 MB or 2 MB.
- **Keep it private** — images are processed locally, with no file uploads.
- **Use it anywhere** — responsive layout with light and dark themes.

Supports **JPEG, PNG, WebP, GIF, and BMP**. Up to **50 images**, **15 MB each**.

## Run locally

Requires **Node.js 22.18+**.

```bash
npm ci
npm run dev
```

Open the URL printed by Vite. To build and preview production:

```bash
npm run build
npm run preview
```

Run `npm test` for regression tests. For browser tests, run `npx playwright install chromium` once, then `npm run test:e2e`.

Built with **Solid.js · TypeScript · Vite · Tailwind CSS · jsPDF**.
